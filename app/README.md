# app/ — native macOS menu-bar app (Phase 2)

SwiftUI `MenuBarExtra` app. Records a call as **two tracks** and hands them to the
pipeline, which transcribes each separately and merges them into a `[Me]`/`[Them]`
speaker-labeled note in Notion.

- **Me** = your microphone (AVAudioRecorder → `me.m4a`)
- **Them** = system audio (ScreenCaptureKit → `them.caf`)

## Layout
```
app/
  build.sh            # compiles with swiftc, assembles + ad-hoc-signs Echo.app (no Xcode project)
  Echo/
    Info.plist        # LSUIElement (menu-bar only), Microphone usage string
    Sources/
      EchoApp.swift        # MenuBarExtra + AppState (orchestrates record → pipeline)
      AudioRecorder.swift  # TwoTrackRecorder: mic + ScreenCaptureKit system audio
      PipelineRunner.swift # spawns `node <repo>/pipeline/src/index.js --mic= --system=`
      Generated.swift      # AUTO-GENERATED by build.sh (repo path); gitignored
```

## Build & run
```bash
cd app && ./build.sh
open build/Echo.app
```
A 🌊 icon appears in the menu bar. **Start Recording** → (first run) grant
**Microphone** and **Screen Recording** in System Settings, then re-launch if macOS
asks. **Stop & Summarize** runs the pipeline and posts a notification with the
Notion page URL.

## Requirements for a real run
- whisper.cpp built + `ggml-large-v3` and `pipeline/.env` filled (see repo `README.md`).
- `node` on your login-shell PATH (the app resolves it via `zsh -lc`).
